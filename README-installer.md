# Установщик OptiCraft

Установщик собирает игру OptiCraft из исходников прямо на вашем компьютере, под его процессор.
Сам он исходники не скачивает: проект вы загружаете заранее, а установщик кладёте в его папку.

В архиве два файла:

- `Build_OptiCraft.exe` — для Windows x64;
- `build_opticraft.sh` — для Linux x86_64.

## Перед запуском

1. Скачайте исходники OptiCraft (архивом с GitHub или через `git clone`).
2. Распакуйте их в папку. В этой папке должны лежать `CMakeLists.txt`, `src` и `assets`.
3. Положите нужный файл из архива в корень этой папки, рядом с `CMakeLists.txt`.

**Важно:** после успешной сборки установщик удаляет из папки все исходники, `.git` и сам себя.
Остаются только `OptiCraft` (игра) и `assets`. Если исходники нужны, сделайте их копию заранее.

## Windows

1. Дважды щёлкните `Build_OptiCraft.exe`.
2. Откроется окно PowerShell с ходом работы.
3. Когда сборка закончится, окно попросит нажать Enter.

Что происходит внутри:

- ищет g++ (MinGW), CMake, Visual Studio 2022, GLFW и GLM в системе;
- если компилятора нет, скачивает MinGW-w64 вместе с CMake (около 245 МБ);
- если нет CMake, GLFW или GLM, скачивает их;
- собирает игру в Release. При сборке MinGW используется `-march=native`, при сборке через Visual Studio — нет;
- кладёт `OptiCraft.exe` в папку проекта и удаляет исходники;
- удаляет сам `Build_OptiCraft.exe`.

Если сборка не удалась, исходники и exe остаются, а текст ошибки видно в окне. После исправления причины можно запустить exe снова.

## Linux

Откройте терминал в папке проекта и выполните:

```bash
chmod +x build_opticraft.sh
./build_opticraft.sh
```

Скрипт:

- ищет компилятор, CMake, make или ninja, unzip, заголовки X11, GLFW и GLM;
- недостающее ставит через apt, dnf, pacman или zypper. Для этого нужен `sudo` и пароль;
- если пакетного менеджера нет или он недоступен, скачивает CMake, GLFW и GLM из интернета. Заголовки X11 скачать нельзя, их придётся поставить вручную;
- собирает игру и удаляет исходники и сам скрипт.

Опции:

- `--no-system-packages` — не использовать пакетный менеджер, всё скачивать;
- `--keep-sources` — не удалять исходники и скрипт (для отладки).

Пример: `./build_opticraft.sh --keep-sources`.

## Запуск игры

Оба варианта кладут игру в папку проекта:

- Windows: `OptiCraft.exe` (двойной клик);
- Linux: `./OptiCraft` из этой папки.

Папка `assets` должна лежать рядом с игрой. Настройки (`options.txt`) игра создаёт рядом с собой.

## Частые проблемы

- **Windows: SmartScreen или антивирус ругаются на exe.** Файл не подписан, это ожидаемо. Разрешите запуск или добавьте папку в исключения.
- **Windows: PowerShell не даёт запустить скрипт.** Лаунчер запускает PowerShell с `-ExecutionPolicy Bypass`, но политика, заданная администратором, может этому мешать.
- **Linux: нет заголовков X11.** Установите пакеты:
  - Debian/Ubuntu: `sudo apt install libx11-dev libxrandr-dev libxinerama-dev libxcursor-dev libxi-dev`;
  - Fedora: `sudo dnf install libX11-devel libXrandr-devel libXinerama-devel libXcursor-devel libXi-devel`.
- **Не хватает места.** Для сборки нужно около 1 ГБ свободного места на диске, временные файлы удаляются в конце.
- **Игра не запускается на другом компьютере.** Сборка делается под процессор той машины, где запущен установщик. Соберите игру на том ПК, где будете играть.
